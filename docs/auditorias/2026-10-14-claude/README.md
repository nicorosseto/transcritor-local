## Como reproduzir

Na raiz do repositório, com as dependências do pedido instaladas, FFmpeg e Tesseract (`por`) no `PATH` e Python com Tk:

```bash
python3.12 docs/auditorias/2026-10-14-claude/reproducoes/k04_ocr.py
xvfb-run -a -s "-screen 0 1366x768x24" python3.12 docs/auditorias/2026-10-14-claude/reproducoes/k01_ler_pasta_e_transcrever.py
```

Cada script diz no cabeçalho qual achado reproduz e como rodar; os que abrem a janela precisam do `xvfb-run`. Todos trabalham em diretórios temporários, não baixam nada e não tocam a pasta do usuário (o `k04` usa um `XDG_DATA_HOME` temporário).
