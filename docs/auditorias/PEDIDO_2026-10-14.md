## Como rodar

```
python -m pip install -r requirements.txt pytest pyflakes
python -m pytest -q                       # 87 testes
python -m pyflakes transcritor tests
# fumaça de interface (Linux): xvfb-run -a -s "-screen 0 1024x768x24" python ferramentas/fumaca/maquina_limpa.py
```
