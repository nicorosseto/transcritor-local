# Transcritor Local v0.1.14 (beta)

Primeira versão pública. Transforma uma pasta de vídeos em arquivos Markdown que qualquer IA consegue ler, com a fala transcrita e, opcionalmente, o texto que aparece na tela. Tudo roda no seu PC.

## Como baixar e abrir

1. Baixe `TranscritorLocal-windows.zip` abaixo e descompacte numa pasta **fora do OneDrive** (ex.: `C:\TranscritorLocal`).
2. Abra `TranscritorLocal.exe`. Na primeira vez, a página **Preparação do PC** baixa, com um clique em cada botão e uma única vez: o FFmpeg (~115 MB, versão oficial conferida por SHA-256) e o modelo de transcrição (~0,5 GB no modo Rápido, ~1,6 GB no Equilibrado e no Preciso).
3. Para ler o texto da tela, instale o Tesseract pelo botão da própria página.

**Aviso do Windows e do Chrome:** o programa ainda não tem assinatura digital. O Chrome pode chamar o arquivo de perigoso e o Windows pode mostrar "O Windows protegeu o computador". No Windows, clique em **Mais informações → Executar assim mesmo**. Para conferir que o arquivo é o publicado aqui, compare o SHA-256 do `.exe` com o desta página (o `SHA256.txt` dentro do zip serve só para conferir a cópia, já que vem no mesmo pacote):

`SHA-256 do TranscritorLocal.exe: <preenchido na publicação>`

```powershell
Get-FileHash .\TranscritorLocal.exe -Algorithm SHA256
```

## Como foi testado

- 112 testes automatizados a cada mudança, no Linux e no Windows (Python 3.11 e 3.13); no Windows, os 4 de OCR são pulados porque o CI não tem o Tesseract.
- Duas auditorias independentes antes da publicação, com os bloqueios corrigidos.
- 5 rodadas de uso real num PC com Windows, só CPU: vídeo de 36 min, fala a ~1,7x no modo Equilibrado.
- Primeiro uso numa máquina limpa (Windows Sandbox, 4 GB de RAM, sem nada instalado), de ponta a ponta.
- Teste cego: três IAs sem nenhum contexto leram os arquivos gerados; nenhuma inventou conteúdo.

## Limitações conhecidas

- O texto de tela sobre fundo colorido (caixas de diagrama) pode sair incompleto. Anexe a pasta do **Pacote para IA** inteira (o `.md` e as imagens), não só o `.md`.
- O modo Rápido erra mais nomes e termos técnicos; use o Equilibrado sempre que o PC tiver memória.
- Não identifica quem fala.
- O Tesseract é instalado à parte.
- Dependências Python ainda não fixadas por hash (o FFmpeg já é); programa sem assinatura digital.
- O zip não traz nenhum programa GPL: o FFmpeg é baixado pelo próprio app, direto do distribuidor.
